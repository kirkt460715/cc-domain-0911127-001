# 病区改造容量模拟

日历模块校验封闭时段与病区约束，事件引擎推进患者等待、入院、转移和离开。成对比较使用同一患者需求，网格分析保留合法方案与容量债务诊断。

时间为场景内的离散单位。容量债务是改造排程的暴露量，不是实际可用床位。到达需求由本地合成分布产生，输出仅用于规划演练。

## 运行

Node.js 22，仅使用内置模块。无需安装第三方包。 在项目根目录执行，命令不访问公网。演示在临时目录内创建数据，结束后自行清理，不需要预置凭据或另启服务。

```sh
node ward-sim.js demo fixtures/wards.json
```

## 开发检查

测试覆盖当前产品的核心计算、边界输入、事务或版本恢复及异常路径。编译或语法检查可单独运行。

```sh
npm test
npm run build
```

## 容器复现

先在有网络的准备阶段取得运行镜像。之后可在断网容器中复制项目到临时工作区运行，避免向源目录写入缓存。

```sh
docker build -t local/ward-sim .
docker run --rm --network none local/ward-sim
```

具体接口参数可通过主入口的帮助命令查看。数据库、归档和导出文件应存入调用者指定的工作目录，不提交到源码仓库。
